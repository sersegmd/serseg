# SERSEG Language support

Adds `.ser` syntax highlighting, snippets, diagnostics on open and save, and build/run commands. Diagnostics require the `serseg` compiler on PATH. The extension reports the first compiler error. Non-ASCII diagnostic columns may be approximate. This extension does not include a language server, formatter or symbol navigation. It has not yet been tested inside VS Code.

Use **SERSEG: Build current file** or **SERSEG: Run current file** from the command palette. The compiler and GCC must be installed separately. See the project's Arabic guide for installation instructions.
